WUHAN REAL ESTATE LEAD GENERATION · V2

武汉房产获客
双 IP 三发执行方案

目标不是“把房子拍出来”，而是让真正会买、会委托的人看完后主动咨询。高森负责把房子拍得有故事、有质感；杨总负责把内容打进武汉本地高端置业语境；同一套房再生成一个直接为售房转化服务的版本。

核心目标：获客、带看、委托、成交核心 IP：高森 + 杨总每套房：一组素材、三条独立内容
账号口径：核心 IP 只做两个。为了实现“一个房子、三个账号、三条视频”，第三个是已有或新设的房源转化分发号，不再打造第三个人设、不额外增加创作负担；它只承接直接卖房与线索转化。

01 / Business First

先把“做内容”改成“做售房获客”

客户不缺房源信息，缺的是一个能帮他判断“这套房适不适合我”、并且愿意把咨询交出去的人。内容必须同时完成三件事：让房子被看见、让团队被信任、让客户愿意下一步联系。

01
房源被正确理解
不只展示大、贵、漂亮，而是说清它对应怎样的家庭、时间和生活选择。
02
武汉本地被持续识别
杨总用真实的沙湖、东湖、严西湖等现场与语言，稳定打本地标签。
03
线索能被承接
每条片子都有明确对象与下一步，不把播放量当成唯一结果。
乙方的核心交付不是“给脚本”，而是：为每套房定成交切口、做实景导演和镜头设计、把一组素材拆成三条不同内容、完成本地化发布与数据复盘。甲方提供真实业务与房源，乙方负责把它生产成可以带来咨询的内容资产。

03 / Core IPs

不是换个人讲同一套房，而是各自解决不同的成交问题

IP 01 · 高森账号
高森｜武汉湖畔别墅故事 （工作名）
把空镜升级为“有故事的房子”
让客户先对生活方式产生代入
不强迫高森出镜房子 + 故事性旁白质感、情绪、生活代入每套房 1 条主版本

优化方向

  • 保留“空镜 + 旁白”的优势，但每条先有一个真实问题或选择，而不是泛泛讲人生感悟。
  • 空镜中加入真实动作与生活证据：推门、开窗、摆餐具、走到湖景窗前。
  • 每条片只服务一个情绪：想安静、想陪伴、想把周末留给家、想换一种城市生活。

固定结构

  • 5 秒钩子：先说这套房适合 / 不适合谁。
  • 30–45 秒故事：用空间动线、光线、景观讲一种日常，而非报户型参数。
  • 10 秒证据：给出一个真实、可拍的核心卖点。
  • 5 秒收口：克制地落回“如果你也在找这种生活”。

画面标准

  • 拍摄前先踩光；一套房至少选定一个最有表现力的时段。
  • 固定色彩、收音、运镜和字幕节奏，形成高森账号的辨识度。
  • 不堆航拍，不用连续十几个空镜；每一个镜头都要推动故事。
示例开头：“住在武汉湖边的人，最后买下的通常不是面积，是每天打开窗帘时那十分钟。”
IP 02 · 杨总账号
杨总｜武汉湖居置业 （工作名）
用武汉本地实景和判断
获得本地高端买方与业主信任
杨总真人出镜武汉地名强标签当地判断、房源选择每套房 1 条本地版

账号角色

  • 不是泛讲市场的“房产专家”，而是带用户到武汉具体湖区、具体房子里做判断的人。
  • 核心标签：武汉、沙湖、东湖、严西湖等真实业务覆盖湖区与高端改善场景。
  • 用短而有判断的出镜建立信任；不需要全程站着口播。

单条内容结构

  • 前 5 秒：杨总出镜 + 一个真实地名，如“今天在武汉东湖边，讲一套不适合所有人的房子”。
  • 中段：进入房子，只讲一个本地化判断：谁适合、什么需求会被满足。
  • 结尾：杨总在房内 / 湖边收口，给出一条克制的看房建议。

不能做成什么

  • 不能每条都从多个武汉地标切到多个房间，像城市宣传片。
  • 不能为了标签硬塞“东湖、沙湖、严西湖”——真实在哪，就只讲哪。
  • 不能只报面积、总价、装修；这样无法建立杨总不可替代的本地判断。
示例开头：“在武汉沙湖边看房，先别急着看湖景。你真正要确认的是，下班后的时间是不是还属于自己。”

核心任务

  • 承接“武汉 + 板块 + 别墅 / 大平层”的搜索和直接房源咨询。
  • 把高森、杨总带来的兴趣，收束成预算、区域、户型、看房时间等有效需求。

内容逻辑

  • 用同一素材，删掉泛情绪，补上“这套房的客户匹配条件”。
  • 只讲 3 个真实可核实的卖点 + 1 个带看动作。
  • 视频短一些、信息更清楚，但不是机械报参数。

使用边界

  • 不另起第三个人物、不另配第三套日常拍摄团队。
  • 需要有明确的私信、电话或带看承接人，并记录线索来源。
  • 涉及价格、地址、业主信息均按授权范围发布。
04 / One Property, Three Cuts

同一组素材，剪成三条不同的成交内容

三条片子的差别不只是换开头、改 BGM 或裁成不同画幅。要让同一套房分别服务“喜欢这套生活的人”“相信杨总本地判断的人”“准备直接看房的人”。

发布账号观众看完应该得到什么叙事切口建议时长收口动作
高森“我好像能住进这套房的生活。”一个生活选择 + 空间与情绪的证据。故事旁白为主，房源信息点到为止。60–90 秒“如果你也在找这种生活，可以来看看。”
杨总“我知道这套房在武汉哪里、适合谁，杨总懂这里。”一个真实湖区 / 板块 + 一个本地判断 + 这套房的匹配人群。杨总短出镜。45–70 秒“在武汉看这类房，先把[真实判断问题]想明白。”
房源转化号“这套房是否值得我现在约看？”客户画像 + 3 个真实卖点 + 看片 / 带看的下一步。不讲泛故事。30–50 秒“想看这类房，私信留下预算和区域需求。”
一房三发的正确顺序：先做一次房源拍摄方案 → 拍一套可复用的高质量素材 → 先定三条内容的不同核心句 → 最后分别剪辑、封面、标题、发布。不是拍完一条高森视频后，再临时硬改两条。
05 / What Party B Actually Delivers

乙方要做出甲方不应自己承担的专业价值

甲方当然可以拍日常空镜、录一段口播；乙方的价值应放在“把真实业务生产成可成交的内容产品”这件更难的事情上。

01

单房选题策划

拍前先确认：这套房真正卖给谁、最值得讲的一个点、三个账号分别说什么。没有选题结论，不开机。

02

实景导演与影像标准

踩点找光、定拍摄时段、设计动线与动作、统一镜头语言、收音、调色和字幕。把“房子空镜”做出账号质感。

03

三条独立内容成片

不是三种裁切，而是三套叙事、三组开头、三张封面、三种收口和三套本地化标题。

04

武汉标签设计

为杨总选择真实可拍的武汉场景与准确地名，把城市信息、房源位置和用户决策自然写进前 5 秒。

05

发布与线索复盘

记录每条内容的来源、观看、有效私信、带看、委托和用户问题；用成交动作判断内容，而不是只报播放量。

06

可复制的房源内容 SOP

跑通 2–3 套房后沉淀拍摄清单、镜头库、文案结构和审核标准，让团队可以稳定放量。

06 / Wuhan Localization

杨总打武汉本地标签：一条只用一个真实地点、两个主要场景

武汉实景不是用来堆镜头的，是用来证明杨总真的在这里做业务、懂这里的居住选择。地名必须与真实房源位置、实际业务覆盖一致。

01
3–7 秒 · 真实武汉现场

只选一个地名

如真实在东湖、沙湖或严西湖附近，就拍一个可识别的真实周边镜头，由杨总说出地点。不要在一条里串多个湖区。

02
35–55 秒 · 房子主空间

只讲一个判断

进入客厅、窗景、花园或动线最强的一个空间，围绕“谁适合、为什么”讲清楚。镜头主体始终是房子。

03
5–10 秒 · 收口细节

一处细节作证

用窗外、湖景、灯光、门厅或杨总短出镜收口。总场景控制在 2–3 个，宁少勿杂。

位置本地标签做法正确示例不要这样做
标题武汉 + 真实片区 / 湖区 + 房型 / 决策问题“武汉东湖边的别墅，什么家庭住起来最舒服？”“武汉最顶级豪宅，错过后悔”
前 5 秒杨总说出一个真实地点和一个判断“今天在武汉严西湖附近，讲一套适合把周末留给家的房子。”多个武汉地标快速拼接后才进入房子
字幕 / 话题自然保留武汉、真实片区、别墅 / 改善等关键词“武汉沙湖改善置业｜真实房源现场”虚构周边资源、夸大区域价值或承诺升值
07 / Property Battle Card

每拍一套房，乙方先交这张“单房作战卡”

这张卡把脚本变成可执行的内容生产计划，也是甲方无法用“自己拍几个空镜”替代的关键交付。

《[房源名称 / 内部编号]》一房三发作战卡

所有方括号内容必须基于真实房源、授权信息和当天实勘填写。

01｜谁会买[预算 / 家庭阶段 / 区域需求 / 当前痛点]
02｜只讲一个卖点[这套房最具表现力的空间、景观或生活动线]
03｜高森版本[故事句：这套房解决的是哪一种生活选择]
04｜杨总版本[武汉真实地点 + 杨总要给出的本地判断]
05｜转化版本[3 个可核实卖点 + 要承接的咨询问题]
06｜视觉计划[踩点时间 / 最佳光线 / 主空间 / 动作镜头 / 禁拍区域]
07｜素材授权[价格、位置、业主、门牌、室内私人物品的公开边界]
08｜线索负责人[谁接私信 / 谁约看 / 如何回填线索来源]

一套房的基础镜头库

  • 外部环境 2–3 组：只拍与故事和地名有关的部分。
  • 进门、走动、开窗、停留等动作镜头 4–6 组。
  • 主空间的远 / 中 / 近景 6–8 组，保证剪辑有层次。
  • 真实生活细节与“卖点证据” 5–8 组。
  • 杨总的本地出镜 2–3 组；每组一句即可。

成片前的四个检查

  • 是否一句话就能说清“这套房适合谁”？
  • 三个版本的开头、论点、结尾是否不同？
  • 武汉地名与实景、房源是否真实对应？
  • 是否留有自然的看房 / 私信动作，而非强硬推销？
08 / First Launch Cycle

先用 2 套真实房源跑一轮，不用一开始大量铺号

第 1–2 天

旧号审计

确认高森旧号数据、粉丝区域、标签、内容质量和是否值得沿用；确定杨总账号主体与本地资料。

第 3–4 天

两套房选题会

分别完成两张单房作战卡，选定杨总的武汉实景地点和高森的故事切口。

第 5–8 天

集中拍摄 + 三剪

每套房一次高标准拍摄，先后完成高森版、杨总版、房源转化版，共 6 条成片。

第 9–14 天

发布与复盘

按账号分别发布，记录有效咨询、评论问题、带看与委托。复盘后再决定下一批房源和出镜方式。

目标顺序不能反：先把能带来有效咨询的“房源内容模型”跑通，再考虑扩展更多经纪人账号、宏大品牌故事或泛流量剧情。对于当下阶段，成交线索、带看、委托才是内容是否有效的最终判断。
本版基于项目会议纪要与最新业务纠偏制作：核心以获客和售房为中心，明确高森、杨总两个 IP 的不同分工，并将“一房三发”落为可执行的拍摄、剪辑、发布与线索承接机制。品牌名、第三个转化号主体及具体房源信息均须由甲方最终确认。
